# Changelog

## 0.2.0-beta.1 — 2026-11-11 — first public beta

Consolidates the private Scene Planner tests and fixes into one complete package.

- Large local planning page for DaSiWa/Eros H3 Simple and Pro source workflows; current-graph capture, manual import and four starting templates.
- Up to six start/guide/end images, ordering, timeline selection, large crop preview, padding/stretch options and automatic first-image orientation suggestions.
- Expanded trial/portrait/landscape/square/custom resolutions, including 1088 × 608.
- H3-aligned actual frames/FPS/duration display, explicit duration-control guidance and synchronization of recognized exclusively owned legacy controls.
- Timed scene events, editable/copyable prompt and optional textual sound direction.
- Local LoRA search/add/remove/toggle/strength controls for recognized loaders; compact enabled-only list, disabled-row recovery and scoped source reset.
- Source/planned comparison with labels on each card; source snapshot remains immutable and later ComfyUI edits require a fresh import.
- Local browser draft recovery, portable project JSON with images/source graph, and separate executable workflow export.
- Optional local Ollama translation with explicit review/apply; no model downloads in the installer.
- Prepared-image recognition in ComfyUI, missing-source recovery and conservative rejection of ambiguous loader/graph layouts.
- Eight UI languages, English-first release files, English/Hungarian beginner instructions, package hashes and Windows installer backups.

Scope: H3 only. LTX is postponed. No generation engine, automatic queueing, actual audio synthesis/repair, automatic transitions or lip-sync engine is included.

Validation distinguishes isolated code/browser/installer checks from actual model generation. No general video-quality or hardware-compatibility guarantee is claimed.
